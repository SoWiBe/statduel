# Правила игры (statduel)

Версия 1. Пока без кода, только договорённости.

## Участники и вход
- Партия на двоих, игроки заходят по никнейму (без паролей).
- Игроки встречаются в комнате.

## Колода и раздача
- Колода состоит из уникальных карточек, повторов нет.
- Каждый игрок получает по 5 карточек, раздача случайная, карточки у игроков не пересекаются.
- У каждой карточки свой набор показателей (интеллект, скорость, ловкость и т.д.). Набор показателей одинаковый для всех карточек.
- Персонажи в публичном репозитории выдуманные (без Смешариков и других защищённых персонажей).

## Раунд
- Партия состоит из 5 раундов, в каждом раунде игрок разыгрывает одну карточку из руки.
- Показатель раунда выбирает один из игроков. В первом раунде это случайный игрок, в каждом следующем раунде выбирающий меняется.
- Выигрывает раунд тот, у чьей карточки выбранный показатель выше.
- Сыгранная карточка больше не возвращается в игру.
- Ничья по показателю: обе карточки выбывают, раунд никому не засчитывается.

## Видимость
- Карточки в руке соперника скрыты.
- Видны только карточки текущего боя (после розыгрыша раунда).

## Итог партии
- Выигрывает тот, у кого больше выигранных раундов.
- Равное число побед это ничья по партии. Это нормальное завершение, дополнительных раундов нет.

## Открытые вопросы
1. Порядок шагов в раунде: сначала оба игрока тайно выбирают карточку, потом выбирающий называет показатель? Или показатель называется до выбора карточек?
2. Сколько показателей у карточки (предложение: 4-5) и в каком диапазоне значения (предложение: 1-100)?
3. Раунды всегда ровно 5? При 5 карточках на руках это так, если никто не может пропустить ход.
